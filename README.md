# ReceivAI

AI-powered payment risk prediction and cash flow management
platform for B2B SMEs.

## Overview

ReceivAI helps SMEs identify invoices that are likely to be
paid late and understand the potential impact of delayed
payments on their cash flow.

## Core Features

- Invoice management
- Payment risk prediction
- Cash flow forecasting
- AI financial copilot

## Technology

- React
- Spring Boot
- MySQL
- Python
- Machine Learning
- AI Agent
